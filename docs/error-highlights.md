# エラー箇所のハイライト

入力や確定に失敗したとき、修正対象を赤枠と説明文で表示します。エラー一覧の項目を押すと該当欄へ移動し、最初の不備へ自動的にフォーカスします。折りたたまれた詳細欄は移動時に開きます。入力値は消しません。

対応: 日付・店舗・商品名・カテゴリ・整数金額・数量・税抜価格・合計照合・税率・割引・配賦承認・カテゴリ名の重複など。明細番号で対象を区別します。合計不一致では合計欄に照合案内を出し、どの商品価格が間違ったかは推測しません。

編集した項目の強調は外れますが、修正が正しいと保証するものではありません。保存・計算・確定を再度実行して確認してください。通信や外部APIのエラーは入力欄の誤りとは区別し、画面のメッセージのみ表示します。

実装: APIの既存detailを保持したままfield_errors（loc/message/derived）を追加し、static/field-errors.jsが入力欄へ対応付けます。日本語メッセージの文字列解析でエラー箇所を推測しません。aria-invalid/aria-describedby、一覧からのキーボード移動に対応しています。

検証: 自動テスト111件成功。Chromiumで2番目の明細だけの強調、最初のエラーへのフォーカス、一覧リンク、編集時クリア、カテゴリ名重複、小数入力、詳細欄展開、通信エラーの誤強調防止、390pxで横はみ出しなしを確認。合成データの画像はartifacts/error-highlights/に保存。実データ・資格情報・税計算式は変更しません。

バックエンド変更を含むため、反映にはアプリを起動し直し、ブラウザを再読み込みしてください。

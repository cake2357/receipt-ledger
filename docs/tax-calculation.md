# 税抜価格から税込額を計算する

1. レシートの確認画面で「税別レシート」をオンにします（税抜OCR結果では既にオン）。
2. 明細の「税抜明細額（数量込み）」と分類を確認します。税込円は自分で計算する必要はありません。
3. OKの割引を使う会計は「OK食品割引」から「対象額の3/103を割引してから課税」を選択します。初期状態は適用しないです。
4. 「税抜額から税込を計算」で案を表示し、「この税込計算を適用」を押します。
5. レシートの印字合計との一致を確認し、計算値の承認・画像確認にチェックして確定します。

## 税率・例外

分類・設定でカテゴリごとに8%/10%とOK割引対象を変更できます。既存カテゴリの初期値は食料品で始まる名前、おやつが8%・割引対象、その他が10%・対象外です。新規カテゴリは税率を選んで保存してください。育児カテゴリにも食品などが混ざる場合はカテゴリを分けるか、明細の税率・OK割引を上書きできます。

税込表記のレシートに重ねて税を加えないでください。自動計算には税別モードが必要です。不明価格を合計の差額から補完することはありません。

## 計算方法と端数

- OK割引: 対象明細の税抜合計 × 3 ÷ 103、1円未満切り捨て。3%ではありません。
- 割引総額を対象明細の税抜額に比例配分。各明細の切り捨て残額を小数部分の大きい順（同率は明細順）に配分します。
- 割引後額を8%/10%別に集計し、税率ごとに税額の1円未満を切り捨てます。各税率の明細へ同じ方法で配分します。
- 印字値は上書きせず、計算値は別に保存します。混合税率にも対応します。

これは指定ルールによる家計簿用の計算です。店舗の割引除外品・支払条件・端数処理を完全に再現する保証はありません。印字と異なる場合は対象商品を見直すか、「印字の割引総額を対象商品に配分」を選んで印字割引額を利用してください。従来の印字税総額を用いる配賦も残しています（従来方式は単一税率のみ）。

税込明細額を手修正すると、その行は「税込額を手修正済み」と表示されます。元の割引・税の計算記録を残したまま、手修正した税込額で保存・集計します。印字合計と全明細を照合し、確認・承認に再チェックして確定してください。合計不一致・不明金額は確定できません。税抜額・税率・割引対象などの計算元も変えた場合は再計算が必要です。再計算を適用すると手修正額も計算値に置き換わります。

旧版で手修正して「配賦元や計算値が変わっています」と表示された下書きは、照合欄の「保存済みの手修正額を採用」を押すと、入力し直さず手修正として扱えます。金額は変わりません。確認・承認に再チェックして確定してください。

分類設定や価格・税率・対象を変更した下書きは承認を取り消し、明示的な再計算が必要です。確定済みの取引額はカテゴリ税率を変更しても更新しません。

旧DBにはカテゴリの税率・割引対象列を追加します。初回変更前に data/before-tax-rules-*.sqlite3 の整合性のあるバックアップを作成します。
